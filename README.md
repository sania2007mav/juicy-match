# Сочный ряд

Браузерная игра «три в ряд» про фрукты и ягоды. Своя графика, свои имена и свой звук: яблоки, апельсины, лимоны, груши, черника и виноград. Полосатик чистит ряд или столбик, сочный заряд взрывает квадрат 3×3 дважды, спектр снимает цвет. Рекламы, покупок и таймеров нет.

Игра открывается как статический сайт: [https://sania2007mav.github.io/juicy-match/](https://sania2007mav.github.io/juicy-match/).

## Как играть

- Поле 8×8 или 9×9. Меняй соседние фрукты свайпом, перетаскиванием или двумя нажатиями. Неверный обмен возвращается назад.
- Три и больше в ряд исчезают, фрукты падают, пустые клетки заполняются. Каждая волна каскада увеличивает множитель очков.
- Четыре в ряд — **полосатик** (направление зависит от жеста). Угол или буква Т — **заряд**. Пять в ряд — **спектр**. Особые фрукты комбинируются друг с другом.
- Цели уровня: очки, лёд под фруктами, сбор цвета, нектар, который нужно довести до нижнего края. Ходы ограничены, за результат дают 1–3 звезды.
- Препятствия: одинарный и двойной лёд, ящики, лианы, пустые клетки фигурного поля.
- Когда цель выполнена, оставшиеся ходы превращаются в особые фрукты и срабатывают.
- Если ходов не осталось, один раз за попытку можно взять **+5 ходов** бесплатно.
- Если ходов нет, поле перемешивается само. После пяти секунд без действия подсвечивается подсказка.
- Звёзды пополняют запас бустеров: давилка, перемешка, полосатик. Купить их нельзя.
- Языки: русский (по умолчанию), қазақша, English. Звук синтезируется в браузере, его можно выключить. На телефоне сильные комбо коротко вибрируют.
- Прогресс, язык и запас бустеров хранятся в `localStorage`. Игра работает офлайн как PWA.

На карте 42 уровня. Первый уровень уже содержит полосатик и заряд, чтобы особые фрукты было видно сразу.

## Запуск

Нужен любой статический сервер из корня репозитория. Пути относительные, поэтому страница корректно открывается и с `/`, и с `/juicy-match/`.

```bash
npm start
```

Сайт будет на [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Сборка не нужна: GitHub Pages отдаёт файлы как есть. Файл `.nojekyll` отключает обработку Jekyll.

## Проверки

Правила поля — обычные тесты Node:

```bash
npm test
```

Они проверяют совпадения, особые фрукты, комбинации особых, каскады, цели и то, что у каждого уровня на старте есть ход.

Сценарий в браузере (нужен Chromium для Playwright) открывает карту, проходит первый уровень и сохраняет снимки:

```bash
npx playwright install chromium
npm run test:e2e
```
